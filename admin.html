Connect to GitHub

This page only asks for a token because it isn't being served from admin.tahirqadri.com.pk right now — check the address bar. Opened there, signing in is enough and this dialog never appears.

Publishing needs a token with permission to write to TahirQadri88/PersonalWebsite. Make a fine-grained one at github.com/settings/personal-access-tokens: choose Only select repositories → this repository, then under Repository permissions set Contents: Read and write. Give it an expiry. Nothing else is needed.

Left unticked it is forgotten when you close the browser, which is the safer choice on a shared or lost device. A stored token can push to your repository, so treat it as a key.
